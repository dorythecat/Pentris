# Pentris
My own version of Tetris, with pent- instead of tetr-ominos! :D

# How to play
You can use the left and right arrow keys to move thee pentominos side to side,
the up arrow to rotate them, and the down arrow to lightly speed up their fall.

Every pentomino you correctly place warrants you ten points, and every time you
clear a line, you get 100 points guaranteed, though, if you clear multiplee lines
at once, the score increases exponentially!
